Modifier - Modify /system systemless
====================================

A template Magisk module to modify /system. 

## Why does this exist?

I know many will question the existence of this, 
but I just don't think there is currently a template simple enough for beginners to make their own modules.
I hope this module will be a beginning for them.

## Quick Start

Simply modify the files in /system and repackage them as a zip.
